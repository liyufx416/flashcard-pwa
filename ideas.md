- Add a review feature to the study screen. Review mode should filter out all the cards that are marked as "Easy" or all cards that do not have a difficulty level. Review mode should apply to both Card view or list view. When in review mode, a "Review Card x of y" should be displayed instead of "Card x of y". User should be able click on the "Review Card x of y" or "Card x of y" to switch between the review mode and the study mode. Add a Review button in the panel that ask for user action when moving past the last card. User will have 3 options: "Yes" to go to the first card of the deck, "Review" to go to the first card of the review mode, and "Done" to go back to the welcome screen.
- Add a repeat feature to the study screen. When user mark a card as "Hard", the card should be repeated within a given period of time. Default period should be 2 minutes, but user can change the frequency to 5 minutes, 15 minutes and 30 minutes. Also a card marked as "Medium" should be repeated within a given period of time as well, in a period 5 times as long as the "Hard" cards. Repeat feature only applies to Card view. List view does not support repeat feature.
- When search for a word and could not find it, the popup should ask if user wish to add the word to the language pair. If user says yes, pop up the screen add new word, and add the word to the language pair. If the search scope is deck or filtered, and the deck is not rank-based deck, the word should be added to the deck as well. Reuse the same add new word screen that is in Manage screen. If the current search target includes the "Word" field, the word user entered should populate the "Word" field to the add new word screen. Otherwise it should populate the "translation" field of the add new word screen. Once the word is added, go to Study screen and display the word as search result.
